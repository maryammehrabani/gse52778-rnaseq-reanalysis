# قرار دادن کد و نمودارهای GSE52778 در GitHub

این بسته، بازتحلیل دادهٔ عمومی واقعی GSE52778 است؛ آزمایش اصلی متعلق به Himes و همکاران (۲۰۱۴) است.

## انتشار در حساب خودتان

1. فایل ZIP را Extract کنید و پوشهٔ `gse52778-reanalysis` را باز کنید.
2. در حساب `maryammehrabani` از دکمهٔ `+`، گزینهٔ `New repository` را انتخاب کنید.
3. نام مخزن را `gse52778-rnaseq-reanalysis` و وضعیت را `Public` قرار دهید. برای شروع می‌توانید `Add README` را فعال کنید و سپس README آمادهٔ این بسته را جایگزین کنید.
4. پس از ایجاد مخزن، `Add file → Upload files` را بزنید. **محتویات داخل پوشه** را با زیرپوشه‌ها بکشید و رها کنید؛ خود ZIP را بارگذاری نکنید.
5. فایل `README.md` باید در ریشهٔ مخزن باشد؛ پوشه‌های `data`، `figures`، `results`، `scripts` و `source` کنار آن باشند.
6. پیام تغییر را `Add paired GSE52778 analysis and figures` بنویسید و تغییر را ثبت کنید (`Commit changes`؛ اگر شاخهٔ جدا ساختید، Pull request را ادغام کنید).
7. README آماده، چهار نمودار را به‌صورت خودکار نمایش می‌دهد. نیازی به اجرای کد برای نمایش تصاویر نیست.
8. در بخش `About` مخزن این توضیح را بگذارید:
   `Reproducible paired RNA-seq reanalysis of GSE52778 with PyDESeq2, four figures, and an R/DESeq2 counterpart.`
9. موضوع‌های مناسب: `bioinformatics`, `rna-seq`, `differential-expression`, `pydeseq2`, `reproducible-research`, `drug-response`.
10. مخزن را در پروفایل خود Pin کنید. پس از انتشار، لینک واقعی مخزن را به بخش Code سایت اضافه کنید.

نام مخزن بالا یک پیشنهاد است و در این مرحله هنوز در حساب شما ایجاد نشده است. اگر مخزنی با این نام از قبل دارید، فایل‌های نامرتبط آن را حذف نکنید.

## فایل‌های مهم

- `scripts/analyze.py`: تحلیل Python با مدل جفت‌شدهٔ `~ donor + condition`.
- `scripts/plot_results.py`: تولید چهار نمودار واقعی.
- `scripts/reanalyze_in_R.R`: نسخهٔ R برای اجرای مستقل.
- `figures`: نمودارهای PNG و SVG.
- `results`: جدول نتایج، ورودی نمودارها و کنترل‌های محاسباتی.
- `README.md`: روش‌ها، نتایج، اجرای مجدد، محدودیت‌ها و منابع اصلی.

تحلیل Python واقعاً اجرا شده است. نسخهٔ R به دلیل نبود R در محیط تهیهٔ بسته اجرا نشده و خروجی‌های موجود مربوط به PyDESeq2 هستند. برای ادعای اجرای R ابتدا آن را اجرا و نتایج را بررسی کنید. این پروژه را «بازتحلیل دادهٔ عمومی» معرفی کنید، نه آزمایش جدید یا کشف بالینی.
